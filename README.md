# TS Refrigeração & Climatização

Landing page institucional e responsiva para apresentação dos serviços da TS Refrigeração & Climatização e conversão de solicitações pelo WhatsApp.

## Tecnologias

- React e TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite, normalmente `http://localhost:5173/`.

## Validação

```bash
npm run lint
npm run build
npm audit
```

O conteúdo de produção é gerado na pasta `dist`.

## Métricas opcionais

Copie `.env.example` para `.env` e preencha os IDs apenas quando necessário. Google Analytics e Meta Pixel são carregados somente depois que o visitante aceita métricas no aviso de privacidade.

## Publicação

A URL canônica configurada é `https://gbrsolucoestecnologia.github.io/tsrefrigeracao/`. Antes de anunciar, confirme que ela corresponde ao build aprovado.
